# Verification boundaries

This is a public website and a synthetic browser demo, not a VPN client. It does not route, protect or probe network traffic. Latency values are generated locally to demonstrate testing and sorting. They are not server measurements.

Public software claims remain bound to the recorded source review. A method catalogue links to external projects and standards; it is not evidence that every adapter is qualified or released. No Android download is invented.

Website text is provided in English, Sorani and Kurmanji. The app demo preserves the supplied design's partial language preview: navigation and Grandma Mode have localized controls, while detailed app copy remains English, as labelled in the demo. Native-speaker and assistive-technology user review is not claimed.

Local browser and performance results describe the exact build in the verification receipt. They do not establish physical-device compatibility, field Core Web Vitals, a security audit or production hosting behavior.

Original input archives and private reference material are retained separately on the owner's computer. They are deliberately absent from this distributable source and its production output.
